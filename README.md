# Auto Input Tool

自动键盘输入工具，用于将复制的文本模拟键盘输入，带有 PyQt5 GUI 界面。支持日间/夜间主题切换和窗口置顶功能。

---

## 功能特点

- 简洁直观的 GUI 界面
- 支持复制文本粘贴到预览框
- 一键开始自动输入，支持中文和英文
- 日间/夜间主题切换
- 窗口置顶功能
- 可直接双击 exe 使用（无需安装 Python）

---

## 使用方法

1. 下载 **最新可执行文件**（Windows）：

[Release v1.0.0](https://github.com/L-NoUse/auto-input-tool/releases/tag/v1.0.0)

2. 双击打开软件：
   - 上方三个圆点：关闭、最小化、最大化
   - 📌 置顶按钮：激活后窗口一直置顶
   - 日夜切换按钮：切换主题
   - 中间文本框：粘贴你要自动输入的文本
   - 下方按钮：
     - **开始输入**：点击后，切换到想要输入的位置，自动开始键盘输入
     - **终止输入**：停止自动输入

## 已知问题 / 限制

1. **输入触发限制**  
   - 目前点击“开始输入”后会自动输入到光标所在位置，如果用户没有先选中目标输入框，可能会在错误位置输入  
   - 建议：先点击目标输入框再点击开始输入  

2. **中文输入兼容性**  
   - 中文输入使用 `pyautogui.write()` 时可能不稳定  
   - 已解决方案：使用 `pyperclip.copy()` + `Ctrl+V` 粘贴方式更稳定  

3. **图标问题**  
   - PyInstaller 打包后的 exe 图标可能需要清理 Windows 图标缓存才能显示自定义图标  
   - 状态栏和任务栏图标需要在代码中设置 `self.setWindowIcon(QIcon("autoinput.ico"))`
